PROMPT 1

The editor should support:
1. Drawing a line
2. Drawing a rectangle
3. Drawing a triangle
4. Drawing a circle
5. Adding objects to the picture
6. Deleting objects from the picture
7. Modifying objects in the picture
8. Displaying the picture
Use a 2D character array to store the picture and write separate functions for each operation.

RESPONSE:
Generated a complete menu-driven C program implementing line, rectangle, triangle, and circle drawing along with add, delete, modify, and display operations.
